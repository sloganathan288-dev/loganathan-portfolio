# Loganathan S — Personal Portfolio

A React + Vite + TypeScript portfolio for Loganathan S, final-year B.Tech Artificial Intelligence & Data Science student.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```
